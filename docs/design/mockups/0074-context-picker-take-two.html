What’s deliberate

One tri-state semantics everywhere: whole = one live ref, drill-in for members, unchecking an implied member splits the parent into explicit picks (a deliberate freeze). Every container row — acts and chapters included — carries the same expand caret; search expands everything. A plain query matches titles, tags, and aliases exactly like the Lore pane; # narrows to tags and becomes an app-wide convention (the Lore search gains it too), so the two surfaces stay identical. ★ target-marking unchanged, scene-only.

Not in this mockup

The modal escalation (same panels, re-hosted) — deferred until the popover proves cramped. Parameterized selectors (“by POV”) — v2. The plot kind color is a placeholder; there is no --k-plot token yet.
