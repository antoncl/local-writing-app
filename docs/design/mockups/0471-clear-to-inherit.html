Inherited vs. overridden — one visual language

Provenance is carried by tint: inherited reads muted, overridden reads live (leading with the real ti-versions mark). Inherited rows carry no source label — the source is in the tooltip (hover a muted value). The action shows only on hover of an overridden row, above the mark, and names the source. A general field-display treatment, not wizard-only.
