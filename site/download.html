Get Local Writing App

Free and open source (MIT). It runs entirely on your machine — no account, no subscription, nothing phones home. Pick your platform.

Windows

64-bit installer. Windows shows a SmartScreen warning on first run because the app is unsigned — the download page walks you through it, so grab it there.

Download for Windows →

macOS

Apple Silicon (M-series). macOS blocks it on first open because the app isn't notarized — the download page shows the one-time step around it, so grab it there.

Download for macOS →

Linux — desktop

An AppImage you make executable and run. No warning gates on Linux. Also available as a portable zip.

Download AppImage (x64) Setup guide →

ARM64? See the setup guide for the arm64 build.

Linux — headless / server

Run the backend on a box with no desktop and reach the UI from any browser on your network. Tarball + a systemd install script.

Download server (x64) Setup guide →

ARM64 (e.g. a Raspberry Pi) build in the setup guide.
