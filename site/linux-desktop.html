Download for Linux

A single AppImage: download it, make it executable, and run. No install, no root, nothing to uninstall — delete the file when you’re done. Linux has no “unknown publisher” gate, so there’s no warning to click through.

Download AppImage (x64)

On ARM64, use the arm64 portable zip. There’s also an x64 portable zip if you’d rather not use an AppImage.

Run it

  1. Download the AppImage above.
  2. Make it executable — in a terminal, or via your file manager’s Properties → Permissions → “Allow executing file as program”:
chmod +x local-writing-app-linux-x64.AppImage
./local-writing-app-linux-x64.AppImage

The app opens in your browser at a local address on your own machine.
