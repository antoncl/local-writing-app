Run it as a server

Install the backend on a box with no desktop — a home server, a NAS, a Raspberry Pi — and reach the writing UI from any browser on your network. A tarball plus a one-command systemd installer.

Download server (x64)

On ARM64 (e.g. a Raspberry Pi), use the arm64 server build.

This mode has no password — trusted networks only

The server binds to your whole network (0.0.0.0) so other machines can reach it, and it has no login. Anyone who can reach the box can open your projects.

Only run it this way on a private network you trust, for a single trusted user. Don’t expose the port to the public internet.

Install as a service

  1. Download and extract the tarball on the box.
  2. Run the installer from the extracted folder. It installs to /opt/local-writing-app, sets up a systemd service that starts on boot, and runs it as your user (not root):
tar -xzf local-writing-app-linux-x64-server.tar.gz
cd local-writing-app-linux-x64-server
sudo ./install-server.sh

When it finishes, it prints the LAN address to open, e.g. http://192.168.1.20:8787. Change the port by exporting LWA_PORT before running the installer.

Update later

One command pulls the latest release for your channel (stable or nightly), keeps your current port and service user, and restarts:

sudo /opt/local-writing-app/update-server.sh

It follows the update channel set in the app and skips the download if you’re already current (--force reinstalls anyway).

Manage it

systemctl status local-writing-app      # is it running?
journalctl -u local-writing-app -f      # follow the logs
sudo systemctl disable --now local-writing-app   # stop & uninstall service
