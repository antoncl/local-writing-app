Apple Silicon (M1 and later). Open the disk image and drag the app to Applications.

Download disk image (.dmg)

Apple Silicon only. On an older Intel Mac, build from source — see the GitHub repo. macOS support is experimental.

macOS will block it the first time — that's expected

On first open, macOS says the app “can’t be opened because it is from an unidentified developer” (or that it can’t be verified). Nothing is wrong. To open it once:

Right-click (or Control-click) the app in Applications and choose Open, then confirm Open in the dialog. If you don’t see the option, go to System Settings → Privacy & Security, scroll down, and click Open Anyway.

On newer macOS you may instead see “… is damaged and can’t be opened” — that’s the same unsigned-app block, worded differently. Clear it once in Terminal, then open the app normally:

xattr -dr com.apple.quarantine "/Applications/Local Writing App.app"

Why it happens: macOS clears this warning only for apps signed and notarized through Apple’s paid Developer Program ($99/year). This is a free, open-source project that ships unsigned rather than build that in. The full source is public, so you can inspect or build it yourself.

Install

  1. Download the disk image above and open it.
  2. Drag the app into your Applications folder.
  3. Open it the first time with right-click → Open (see above). After that, it opens normally.
  4. The app opens in your browser at a local address on your own machine.
