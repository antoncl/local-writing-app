Windows

Download for Windows

64-bit Windows 10 or 11. The installer sets up the app and a Start-menu shortcut. One thing to know before you download:

Windows will warn you — that's expected

The first time you run it — the installer, or the app from the portable .zip — Windows shows a blue “Windows protected your PC” box saying the publisher is unknown. Nothing is wrong. To continue:

Click More info, then Run anyway.

Why it happens: that warning appears for any app not signed with a paid Windows code-signing certificate (a few hundred dollars a year). This is a free, open-source project that would rather not build that cost in — so it ships unsigned. You don't have to take our word for it: the entire source is public and you can build it yourself.

Download

Download installer (.exe)

Prefer no installer? Grab the portable .zip — unzip it anywhere and run the app. (Same unsigned-app warning as above, same steps.)

Install

  1. Download the installer above.
  2. Run it. At the SmartScreen box, choose More info → Run anyway (see above).
  3. Follow the installer and launch the app. It opens in your browser at a local address on your own machine.
